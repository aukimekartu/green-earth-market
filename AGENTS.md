# Project rules
- Keep the brandbook's original line icons in BrandIcon and the category hierarchy and legacy aliases in categories; this keeps all navigation consistent without rewriting Shopify tags.
- Calculate unit-price presentation only from explicit metric package quantities, and show low-stock status only from Shopify inventory; never invent quantity or stock data.
- Promotion removal affects storefront presentation only; never mutate live Shopify products or discount rules without confirmation.
